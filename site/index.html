PIPELINE

From ticket to production
in one autonomous loop

📋

Claim

Webhook fires from Linear/GitHub. Nightforge picks the ticket, classifies blast radius, assigns effort level.

→
🧠

Implement

Model router picks the cheapest capable model. Agent gets isolated git worktree. Writes code, runs tests in loop.

→
🚀

Ship

Auto-merge to main. Atomic deploy via symlink swap. Health check runs. Pass = done. Fail = instant revert + retry.

→
📊

Report

Cost logged per ticket. Speed metrics updated. Telegram notification sent. Next ticket claimed automatically.
